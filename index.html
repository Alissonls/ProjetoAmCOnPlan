Finalidade do Projeto

Sobre esta aplicação

Este projeto foi desenvolvido como uma landing page de front-end para plano de saúde com dados fictícios. Ele integra um assistente virtual interativo (AmCo Atendente) para cotações e triagem médica 24 horas.

Perguntas Rápidas

Como funciona a simulação? Você pode clicar nos botões dos planos ou abrir o chat no canto inferior direito para conversar com o AmCo Atendente e obter valores fictícios instantâneos.
Como solicitar atendimento ou cotação? Basta clicar no balão do chat no canto inferior direito para conversar com o AmCo Atendente e obter informações imediatas.
